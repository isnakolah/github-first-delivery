---
name: github-first-delivery
description: GitHub-first work selection, leases, evidence, and delivery-policy guardrails.
---

Run `gfd doctor` then `gfd context --json` before work. Select only Ready, unblocked, unleased leaf work. Claim through `gfd work claim --apply` before branch or edit. Use native GitHub parent and blocker links. Never create local task ledger or autonomous Epic. Submit evidence through `gfd evidence submit --apply` before declaring complete.

Hooks are guardrails. Writer, branch protection, and CI remain enforcement. Review and explicitly trust hook hashes; never bypass trust.
